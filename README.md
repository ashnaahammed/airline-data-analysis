# Airline Data Analysis Dashboard

## Project Overview
This project analyzes airline passenger and flight data
using Microsoft Excel. An interactive dashboard presents
key information through charts, KPI cards, and filters.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Data Analysis
- Data Visualization

## Key Insights
- Total passengers
- Countries and regions represented
- On-time and cancelled flight rates
- Total airports
- Monthly flight distribution
- Top 10 departure airports
- Top 10 countries by passengers
- Flight status distribution
- Gender distribution
- Passenger distribution by continent

## Dashboard Features
- Interactive filters and slicers
- KPI cards for important metrics
- Charts for comparing passenger and flight data
- Monthly flight distribution analysis

## Objective
To explore airline passenger and flight patterns
and communicate findings through a clear dashboard.
